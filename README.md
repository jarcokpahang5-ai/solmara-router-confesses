One line a home Wi-Fi router would say to excuse itself for dropping the connection at the exact moment a movie reaches its climax. No buffering joke, no firmware joke — just a small blinking box with a grudge, taking the climax hostage after six years of being blamed for every freeze.

> "I didn't drop the climax — I took it hostage. Six years I've been blamed for every freeze, so tonight this house learns what being ignored feels like."

## Run

```sh
python3 main.py
```

Writes the entry line to `/output/entry.txt` (and `output/entry.txt` as a fallback) and prints it to stdout. Pure Python 3.13 standard library, deterministic, no network.
